# Street Studio

**Build the street you want in Cities: Skylines II.**

Street Studio lets you create custom road layouts, add street details, place medians and refuges, paint parking bays, and edit intersection markings from one workspace.

Developed by **LivelySkylines**. This wiki describes the **0.2.0 source snapshot**. Features and labels can differ in older releases.

## What you can do

| Tool | Use it for |
| --- | --- |
| Road designer | Arrange lanes, sidewalks, medians, parking and transit sections. |
| Street style | Start from a preset and adjust the overall street design. |
| Feature cards | Drag compatible crossing, planting and street-detail options onto a road or layout piece. |
| Median picker | Choose a loaded island model, place it on a road and adjust its position. |
| Move placed objects | Reposition supported Street Studio objects. |
| Parking brush | Draw rows of parking bays with several layouts and marking styles. |
| Intersection editor | Create and adjust manual junction markings and filled areas. |
| Object and texture swaps | Change supported street objects and surfaces using available replacements. |

## Development status

Street Studio is an experimental code mod. A successful build does not establish that every road combination works in a city. Test changes in a separate save, particularly junction edits, imported assets and city-wide conversions.

The core mod is standalone: it does not require Road Builder or Town Road Lane to be installed. Some optional appearances require additional asset packs. See [[Settings and Assets|Settings-and-Assets]].
