# Medians and crossings

## Continuous medians

Add a median piece to the road layout, then select it to inspect width, paving and compatible decoration options. Some choices require a particular width or an additional model.

A continuous median is part of the road design. A separately placed refuge or island is an object positioned on that design.

## Place an island or refuge

1. Open **+ Place median / refuge**.
2. Choose an available model.
3. Click the road at the **+** outline.
4. Drag its arrows to adjust its position.

The current picker lists:

| Model | Picker description |
| --- | --- |
| Brick pedestrian refuge | 2 × 5.2 m; signs and bollards. |
| Grass median | 2 × 5.2 m; planted island. |
| Accessible crossing island | 2 × 3 m; walking cut-through. |

A disabled card marked **Asset not loaded in this playset** means the model is unavailable. Loading an unrelated FBX source folder is not the same as enabling its built asset package.

Use **Move placed objects** for supported object-position adjustments. A placement tool does not automatically redesign traffic lanes around a new island: reserve space in the street layout.

## Crossing details

Compatible categories expose features such as pedestrian refuges, crossing signs/RRFBs, brick crosswalks, accessible median crossings and in-street yield signs. The exact choices depend on the section and loaded assets.

Use the separate sign/yield setback controls where available. Crossing arrow direction can be adjusted on supported crossing-sign options; check the actual model orientation at both ends of the road.

## Crossing corner height

The median picker offers three clearance presets for fitted crossing corners:

- **Low:** 2 cm.
- **Standard:** 4 cm.
- **Raised:** 8 cm.

These are clearances above the road for fitted crossing corners, not a general height control for every object. The picker says the choice applies to all fitted crossing corners.

## Planting and decoration

Plant pots, grass options and roadside birch planters require compatible pieces and the relevant loaded objects. Birch planters need both a suitable birch tree and a planter object. Spacing and offset controls can be used where offered.

An imported visual island does not prove that pedestrian routing or vehicle avoidance is configured. Test the crossing in a city before relying on it.
